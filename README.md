# Secure Login System

## Description
A Flask-based secure login system that demonstrates secure password hashing with bcrypt, user registration, login authentication, and a dictionary attack demonstration.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- bcrypt

## How to Run

1. Install Flask
```bash
python -m pip install flask
```

2. Install bcrypt
```bash
python -m pip install bcrypt
```

3. Run the application
```bash
py "Secure System.py"
```

4. Open your browser and visit:
```
http://127.0.0.1:5000
```

## Disclaimer
This project was created for educational purposes to demonstrate secure password storage and cybersecurity concepts. It is not intended for production use.
